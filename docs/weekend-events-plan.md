# 周末活动局：改造路线

本仓库 Fork 自 `JosephHu04/sports-club-manager`，保留原 MIT 许可与版权声明。目标是将体育俱乐部系统逐步改造成适合中文社区活动的报名与候补产品。这里记录当前阶段和上线门槛，避免把开发演示误当成可公开使用的服务。

## 阶段 1：本地开发基线

- 默认使用 SQLite，本机无需 MySQL 即可运行 FastAPI。
- `python -m pytest -q` 可直接执行，并在 PR 中自动运行。
- CORS 只允许配置的前端来源；Docker 的数据库密码必须显式设置，MySQL 不对宿主机开放端口。

## 阶段 2：认证与报名可靠性

- 移除公开的默认管理员密码，设计首次管理员初始化流程。
- 将用户密码从 MD5 迁移到 Argon2，同时兼容并逐步升级旧密码哈希。
- 不再通过 URL 查询参数传递密码和登录令牌。
- 为名额上限、重复报名、候补排序与取消后递补添加集成测试，并处理并发竞争。

## 阶段 3：产品体验

- 以“周末活动局”为暂定产品名，重做活动发现、详情、报名状态、我的活动及组织者管理页。
- 保留原报名、候补、签到能力；弱化与体育俱乐部绑定的学号和会员字段。
- 检查桌面与手机布局、键盘操作、空状态、错误提示。

## 上线门槛

当前 Fork **仅供本地开发，不可公开部署供真实用户注册**。完成认证迁移、管理员初始化、报名并发测试、部署密钥配置和备份方案后，再讨论公开预览站。
