# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - Initial Release

### Added
- 👥 Member registration & login (email, phone, member ID, device-based)
- 📅 Event browsing, booking, and auto waitlist when full
- ↔️ Spot transfer between members
- 📱 QR-code attendance check-in system
- 🔍 Account recovery & password reset (SMTP)
- 🛡️ Admin dashboard with member CRUD, event management, stats
- ⚠️ No-show tracking & auto-restriction system
- 🗄️ Dual database support: SQLite (dev) + MySQL 8 (prod)
- 🐳 Docker + docker-compose one-click deployment
- 🧪 pytest test suite with SQLite integration tests
- 📖 Bilingual documentation (中文 / English)
- 📄 API interactive docs (Swagger UI at /docs)
